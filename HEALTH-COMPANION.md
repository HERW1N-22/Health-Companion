Copy .env.example to .env.local and fill credentials locally. Never commit secrets.
Supabase URL, anon key and server-only service-role key are required.
ANTHROPIC_API_KEY enables AI features; USDA_API_KEY enables nutrition search.
API keys are not configured. The imported application has not been runtime-tested.
